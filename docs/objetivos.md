# Objetivos — ProjectLumina

## Objetivo principal

> Poder **administrar y controlar el servidor remotamente** desde diferentes dispositivos mediante una **interfaz centralizada**.

Especialmente:

- Administrar bots.
- Administrar webs.
- Iniciar, detener y reiniciar servicios.
- Consultar estados.
- Ejecutar acciones remotamente.
- Evitar tener que ir físicamente al servidor.

## Objetivo secundario

> **Aprender** programación, administración de servidores, redes y tecnologías relacionadas mientras se construye ProjectLumina, como parte de la formación y futuro profesional.

## Objetivo inmediato

> **Conseguir que ProjectLumina pueda administrar correctamente un bot y una web desde un dashboard web.**

A partir de ahí se construirá el resto del sistema.

## Criterios de éxito del MVP

Para considerar cumplido el objetivo en v0.1:

1. Iniciar/detener/reiniciar un bot y una web desde el dashboard.
2. Consultar el estado en tiempo casi real.
3. Acceder a los logs.
4. Ver métricas básicas del servidor.
5. Accesible desde laptop e iPhone.
6. Con seguridad básica aplicada.
