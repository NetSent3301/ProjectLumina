# Servidor — ProjectLumina

## Servidor inicial

| Aspecto | Valor |
|---------|-------|
| Hardware | Laptop vieja destinada a servidor |
| Sistema operativo | Debian 13 |
| Función | Ejecutar ProjectLumina, bots, webs y otros servicios |

La laptop debe **permanecer encendida y disponible** para administración remota.

## Sistema y procesos

- Servidor: Debian 13.
- Gestión de servicios: systemd.

ProjectLumina interactuará con los servicios del sistema de forma **controlada y estable**.

## Información mostrada

El dashboard puede mostrar → [dashboard.md](dashboard.md#sección-servidor):

- CPU.
- RAM.
- Disco.
- Temperatura.
- Uso de red.
- Uptime.
- Procesos.
- Servicios activos.
