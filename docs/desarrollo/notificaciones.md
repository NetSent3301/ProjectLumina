# Notificaciones — ProjectLumina

Las notificaciones serán una funcionalidad **futura**, **no del MVP**.

## Ejemplo

```
🚨 ProjectLumina

TelegramBot se cayó.
Lumina intentó reiniciarlo.

Estado actual:
🟢 Online
```

## Eventos a notificar

- Bot caído.
- Web caída.
- Reinicio automático.
- Error grave.
- Servidor fuera de línea.
- Alertas personalizadas.

## Posibles canales futuros

- Telegram.
- Discord.
- Email.
- Otros.
