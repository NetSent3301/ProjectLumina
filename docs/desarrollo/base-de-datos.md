# Base de datos — ProjectLumina

## Elección inicial: SQLite

Inicialmente se utilizará **SQLite**, alojado en `data/lumina.db`.

### Ventaja
Simple, sin servidor adicional, suficiente para un MVP personal.

## Datos almacenados

- Bots.
- Webs.
- Rutas.
- Comandos.
- Opciones de automatización.
- Estados.
- Configuración de servicios.

## Migración futura: PostgreSQL

Si el proyecto crece considerablemente, se podrá migrar a **PostgreSQL** (escalabilidad, multi-servidor).
