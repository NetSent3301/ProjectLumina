# 🔐 Autenticacion — ProjectLumina

> Cómo se identifica al usuario en el sistema.

---

## MVP

**No habrá sistema de usuarios.**

ProjectLumina será una **herramienta personal** destinada al propietario del servidor.

---

## Futuro

Podrán incorporarse:

- Login.
- Autenticación.
- Usuarios → [[Usuarios]].
- Roles.
- Permisos → [[Permisos]].
- Dispositivos autorizados.

> Esto será especialmente importante cuando el proyecto llegue a administrar **servidores de terceros** → [[Roadmap#Futuro lejano — Plataforma]].

---

## ¿Cuándo se necesitará?

- Cuando se exponga a Internet → [[Acceso Remoto]].
- Cuando haya multiusuario o servidores de terceros → [[Requisitos#Fuera del MVP]].
