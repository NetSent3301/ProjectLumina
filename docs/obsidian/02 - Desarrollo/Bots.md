# 🤖 Bots — ProjectLumina

> Gestión de bots remota. Función central del proyecto.

---

## Objetivo

El objetivo es **no tener que entrar físicamente al servidor** para iniciar, detener o solucionar un bot.

→ Administración remota según [[Control Remoto]].

---

## Ejemplo (tarjeta del dashboard)

```text
🤖 TelegramBot

Estado: 🟢 Online
PID: 2841
CPU: 1.8%
RAM: 72 MB

[ Iniciar ]
[ Detener ]
[ Reiniciar ]
[ Logs ]
```

→ Se muestra en [[Dashboard#Sección de BOTS]].

## Resumen de funciones

- Iniciar, detener, reiniciar.
- Consultar estado.
- Ver logs → [[Dashboard#Logs]].
- Detectar si está activo o se cayó.
- Auto-inicio y auto-reinicio (futuro) → [[Auto Restart]].
- Guardar configuración → [[Configuracion de Bots]].
