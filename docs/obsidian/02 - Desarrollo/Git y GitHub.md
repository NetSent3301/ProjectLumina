# 🌿 Git y GitHub — ProjectLumina

> Control de versiones del proyecto.

---

## Sistema de control de versiones

El proyecto utilizará:

- **Git** — control de versiones local.
- **GitHub** — repositorio remoto.

---

## Versionado

Se recomienda mantener versiones como:

```text
v0.1.0
v0.2.0
v0.3.0
```

→ Cada versión documentada en [[Changelog]] y en [[Roadmap]].

---

## Buenas prácticas

- Commits descriptivos por cambio.
- Publicar una **release** por cada versión estable.
- Mantener el **CHANGELOG** actualizado → [[Changelog]].
- Guardar este **mapa de documentación** en `docs/`.
