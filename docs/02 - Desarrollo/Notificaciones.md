# 🔔 Notificaciones — ProjectLumina

> Alertas al usuario ante eventos importantes (funcionalidad futura).

---

## Estado

Las notificaciones serán una funcionalidad **futura**, **no del MVP** → fuera del alcance en [Requisitos](../01%20-%20Planificacion/Requisitos.md).

Planificadas para **v0.4+** → [Roadmap](../01%20-%20Planificacion/Roadmap.md).

---

## Ejemplo de notificación

```text
🚨 ProjectLumina

TelegramBot se cayó.

Lumina intentó reiniciarlo.

Estado actual:
🟢 Online
```

## Eventos a notificar

- Bot caído → [Bots](Bots.md).
- Web caída → [Webs](Webs.md).
- Reinicio automático → [Auto Restart](Auto%20Restart.md).
- Error grave.
- Servidor fuera de línea → [Servidor](Servidor.md).
- Alertas personalizadas.
