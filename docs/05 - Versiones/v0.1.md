# 🚀 v0.1 — Base funcional

> Primer entregable del proyecto. Centro de control funcional.

---

## Objetivo

> Crear una aplicación web funcional que **gestione la máquina donde corre** (sistema, servicios systemd, bots y webs) y permita registrarlos y administrarlos desde una interfaz. El acceso remoto queda para una fase posterior.

---
