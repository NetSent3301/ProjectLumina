## Prioridades del MVP

> Orden recomendado de implementación para [v0.1](../05%20-%20Versiones/v0.1.md).

```text
1. Backend funcionando
2. Comunicación frontend ↔ backend
3. Identificación de bots/webs
4. Estado de bots/webs
5. Iniciar/detener/reiniciar
6. Logs
7. Información básica del servidor
8. Manejo de errores
9. Seguridad básica
10. Estabilización
```
