# Contribuir a ProjectLumina

¡Gracias por tu interés en contribuir!

## Cómo contribuir

1. Haz un fork del repositorio.
2. Crea una rama para tu característica o corrección.
3. Realiza tus cambios con mensajes de commit claros.
4. Envía un pull request describiendo los cambios.

## Estándares

- Escribe código limpio y legible.
- Añade comentarios solo donde aporten valor.
- Actualiza la documentación si cambias el comportamiento.
